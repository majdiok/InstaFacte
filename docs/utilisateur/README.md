# Guide utilisateur FactuTrust

Bienvenue dans la documentation FactuTrust. Ce guide vous accompagne pas à pas pour utiliser la plateforme de facturation électronique.

---

## À qui s'adresse ce guide ?

Ce guide est conçu pour les **utilisateurs novices** et les **personnes non-informaticiennes**. Chaque action est expliquée simplement, avec des captures d'écran pour vous guider.

1. **Nouveau sur FactuTrust ?** Commencez par [Premiers pas](01-premiers-pas.md) pour créer votre compte.
2. **Déjà inscrit ?** Consultez le [Tableau de bord](02-tableau-de-bord.md) pour comprendre l'interface.
3. **Un terme vous échappe ?** Consultez le [Glossaire](glossaire.md).
