# 05 - Fiches (Clients et Produits)

Ce chapitre explique comment gérer vos **clients** et vos **produits**.

---

## Clients

Les clients sont les personnes ou entreprises à qui vous vendez des marchandises ou des services.

### Liste des clients

1. Dans le menu, cliquez sur **Fiches** puis **Clients**.
2. La liste de tous vos clients s'affiche.

![Liste des clients](../screenshots/05-fiches/clients-liste.png)

### Créer un client

1. Cliquez sur **Nouveau client**.
2. Renseignez les informations :
   - Nom ou raison sociale (obligatoire)
   - NIF
   - Adresse
   - Téléphone, email
3. Cliquez sur **Enregistrer**.

### Voir une fiche client

Cliquez sur un client dans la liste. La fiche affiche :

- **Informations générales** : nom, NIF, adresse, contacts
- **Devis** : liste des devis envoyés à ce client
- **Factures** : liste des factures émises pour ce client

![Fiche client](../screenshots/05-fiches/client-fiche.png)

Depuis la fiche client, vous pouvez rapidement créer un **nouveau devis** ou une **nouvelle facture** pour ce client.

### Modifier un client

1. Ouvrez la fiche du client.
2. Cliquez sur **Modifier**.
3. Effectuez vos modifications puis enregistrez.

---

## Produits

Les produits sont les articles ou services que vous vendez. Ils peuvent être liés à une gestion de stock.

### Liste des produits

1. Dans le menu, cliquez sur **Fiches** puis **Produits**.
2. La liste de tous vos produits s'affiche.

![Liste des produits](../screenshots/05-fiches/produits-liste.png)

### Créer un produit

1. Cliquez sur **Nouveau produit**.
2. Renseignez les informations :
   - **Référence** ou code (obligatoire)
   - **Nom** ou description (obligatoire)
   - **Prix unitaire**
   - **TVA** si applicable
   - **Gestion du stock** : activez si vous suivez les quantités en stock
3. Cliquez sur **Enregistrer**.

### Modifier un produit

1. Cliquez sur un produit dans la liste.
2. Cliquez sur **Modifier**.
3. Effectuez vos modifications puis enregistrez.

### Produits et stock

Si un produit est configuré pour la gestion du stock, vous pouvez voir son niveau de stock dans la liste et accéder à son historique depuis la section **Stock**.
