# Illustrations – États vides & UX

Placez ici les SVG pour les états vides et les messages UX.

**Fichiers recommandés :**
- `empty-invoices.svg` – Liste de factures vide
- `empty-clients.svg` – Liste de clients vide
- `empty-products.svg` – Liste de produits vide
- `success-check.svg` – Confirmation succès
- `error-warning.svg` – Erreur / avertissement

**Contraintes :** Illustrations abstraites uniquement (pas de personnages).
**Sources :** [Undraw](https://undraw.co), [DrawKit](https://drawkit.com), ou SVG custom.
